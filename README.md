# ANIMEHub - Anime Info Web Application

A premium, highly interactive single-page web application that displays anime details, genres, original posters, trailers, characters, voice actors, and recommendations.

Powered by the **Jikan API v4** (MyAnimeList unofficial API).

## Features
- **Spotlight Hero Banner**: Features a popular anime with full description, rating details, and a floating 2:3 aspect-ratio cover poster.
- **AI Blended Theme**: Sleek slate-indigo dark mode theme with neon blue, purple, and pink glowing aura graphics.
- **Horizontal Genre Scroll**: Clickable genre tags dynamically loaded from the API to instantly filter search results.
- **Dynamic search and sort options** (popularity, top rated, alphabetical).
- **Glassmorphic Multi-Tab Modal**:
  - **Trailer**: Official trailer video.
  - **Overview**: High-res original poster, detailed metadata list, and synopsis.
  - **Characters & Cast**: Renders cast profiles with photos and voice actor details.
  - **Similar Anime**: Recommendations row (click-to-swap content).
- **Performance Caching**: Caches details, cast, and recommendations in memory to bypass rate-limiting and make loading instant.
